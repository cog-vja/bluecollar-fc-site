## 表示仕様
- **PC（表示幅1000px以上）**：ページ右下に**300×250**バナー。
- **スマホ・タブレット（999px以下）**：ページ右下に**224×33**バナー。
- 記事を約30%スクロール後に表示し、スクロールしても画面右下に追従します。
- 「広告」のラベルと、キーボード操作可能な「×」ボタンを広告**の外側**に表示します。
- 「×」で閉じるとブラウザの**同じタブのセッション中**は5記事間で再表示しません。新しいセッションで再表示します。ブラウザで保存が禁止されている場合は、現在のページ中だけ閉じます。
- 現在の表示幅の素材だけを読み込むため、両方のA8バナーが同時に表示されることはありません。
- ユーザーの入力条件・計算機の値は収集しません。

## GitHub Pagesへの反映方法
1. ZIPを解凍する。
2. `bluecollar-fc-site` **フォルダの中身を全て**、GitHubリポジトリ `cog-vja/bluecollar-fc-site` のルートにアップロードして上書きコミットする（フォルダ自体はアップしない）。
3. 新規ファイル `floating-ads.js` がルートにあることを確認する。
4. 公開後、上記5記事で30%以上スクロールして確認する。PCとスマホで画像サイズが切り替わること、「×」で閉じられることを確認する。
5. トップページに追従広告が出ないことを確認する。
6. A8への遷移と成果計測は、公開後にA8の管理画面・GA4で確認する（自己クリックや自己申込みによる成果テストを推奨するものではありません）。
