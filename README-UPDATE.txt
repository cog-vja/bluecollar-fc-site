GA4追加版（2026-10-10）
測定ID：G-XGMNP7Q9VK

導入方法
1. ZIPを解凍します。
2. bluecollar-fc-siteフォルダの中のファイルをすべて、GitHubの既存リポジトリ最上位へアップロードします。
   フォルダ自体やZIPをアップロードしないでください。既存ファイルは同名で置き換えます。
3. GitHub Pagesへの反映後、公開サイトを開き、GA4の「レポート」→「リアルタイム」でアクセスを確認します。
   広告ブロッカーやブラウザの追跡防止設定により、記録されない場合があります。

変更内容
- 記事13本・トップ・サイト説明・プライバシーの計16ページにGA4を追加。
- 検索エンジン確認用HTMLは変更していません。
- 広告クリック：affiliate_click（A8へのリンクのみ）。
- 記事間の移動：internal_link_click（同一ページ内の目次移動は除外）。
- 計算機利用：calculator_use（有効な入力で計算ボタンを押したときのみ）。
- 初期表示の自動計算はイベントに含めません。入力金額・結果はイベントに含めません。
- プライバシーの説明を更新。広告コードと既存記事・表示の改善は維持しています。

GA4側の設定
- 拡張計測のページビュー・スクロール・離脱クリックはオンで構いません。
- 計算機の利用回数には calculator_use を使います。自動のフォーム計測は重複・混乱を避けるため、
  管理→データストリーム→対象のウェブストリーム→拡張計測の歯車→「フォームの操作」をオフにしてください。
- affiliate_click と標準の click は同じ広告クリックで両方記録される場合があります。
  広告クリック数には affiliate_click のみを用い、両者を合算しないでください。
- 広告クリックは申込み完了や報酬発生を意味しません。成果と承認はA8.netで確認してください。
- article_path / destination_path / affiliate_networkをレポートに使うには、GA4でイベント範囲の
  カスタムディメンションとして登録します。まずは標準のページ情報とイベント名で確認できます。
